Versioned components, MLflow tracking, OIDC-based CI/CD, and 30 unit tests.

* [End-to-End Data Platform (2026)](https://github.com/fabianoamaralbr/data-end-to-end) — End-to-end data platform on Azure for stock OHLCV quotes: ingestion with Azure Data Factory, medallion architecture (bronze → silver → gold) with Databricks and Delta Lake, queries via Synapse Serverless SQL, and Power BI visualization. Centralized analytics logic, containerized with Docker, and publicly deployed.

* [Machine Learning Model for Churn (2024)](https://github.com/fabianoamaralbr/churn_model_ml) — Classification model to predict customer churn, with exploratory analysis, business problem definition, and a focus on retention actions to reduce revenue loss.
